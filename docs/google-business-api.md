# Google Business API

The [Google Business API](https://www.coreclaw.com/?utm_source=github&utm_medium=cpc&utm_campaign=L7&utm_term=&utm_id=L7) allows developers to retrieve publicly available business information from Google Maps.

## Available Fields

- Business Name
- Category
- Phone Number
- Website
- Address
- Coordinates
- Place ID
- Rating
- Review Count
- Opening Hours

## Use Cases

- Lead Generation
- CRM Enrichment
- Market Research
- AI Applications
